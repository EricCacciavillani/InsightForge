# Product Overview

InsightForge is a general-purpose multi-agent research orchestrator that uses GPT-5.1 and Gemini to conduct structured research on any domain.

## Core Capabilities

- Decomposes complex research topics into manageable sub-tasks
- Runs parallel research agents with different LLM backends
- Facilitates structured debates between agents for quality assurance
- Produces actionable recommendations with citations
- Supports deep research via web/academic search (Tavily)
- Checkpointing for resumable long-running research sessions

## Default Profile

The default configuration is for BCI (brain-computer interface) gaming research. However, InsightForge is domain-agnostic and works for finance, simulations, software architecture, or any research domain.

## User Interface

Desktop application (Electron) with:
- Dashboard showing recent runs and stats
- Run orchestrator for starting new research
- Results viewer for completed research
- Settings for API key configuration
- Real-time progress via WebSocket
